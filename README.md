# Landing Gala

Landing estática en HTML y CSS. No necesita instalar dependencias ni configurar un proceso de compilación.

## Antes de publicarla

1. Abrí `index.html` y reemplazá los textos de ejemplo por la información de tu proyecto.
2. Cambiá `Gala` y `gala.` si querés usar otro nombre.
3. Reemplazá `hola@tudominio.com` por tu correo en los dos lugares donde aparece.
4. Si querés cambiar colores o tipografías, editá las variables al comienzo de `styles.css`.

## Publicarla gratis en Vercel

La forma más simple es conectar esta carpeta con un repositorio de GitHub:

1. Creá una cuenta gratuita en [GitHub](https://github.com/) si todavía no tenés una.
2. En GitHub, creá un repositorio nuevo llamado `landing-gala`. Podés dejarlo vacío, sin README ni otros archivos.
3. Subí `index.html`, `styles.css` y `README.md` a ese repositorio. Podés hacerlo desde el botón **Add file → Upload files** de GitHub.
4. Creá una cuenta gratuita en [Vercel](https://vercel.com/) y elegí **Continue with GitHub**.
5. En Vercel, elegí **Add New → Project**, buscá `landing-gala` e importalo.
6. En la configuración del proyecto, dejá **Framework Preset** en **Other**. No hace falta completar comandos de build ni directorios especiales.
7. Presioná **Deploy**. Vercel te va a dar una dirección pública terminada en `vercel.app`.

Cada vez que subas cambios al repositorio de GitHub, Vercel volverá a publicar la página automáticamente.

## Verla en tu computadora

Abrí `index.html` con tu navegador. Para esta versión no hace falta instalar nada.
