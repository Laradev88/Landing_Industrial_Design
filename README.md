# Portfolio de Gala Devincenti

Landing estática en HTML y CSS, pensada como portfolio de una estudiante de tercer año de Diseño Industrial. No necesita instalar dependencias ni configurar un proceso de compilación.

## Personalizar el portfolio

- Editá `index.html` para sumar la bio, formación y datos que quieras mostrar.
- Reemplazá las tres tarjetas de muestra de la sección **Proyectos** por los títulos, descripciones e imágenes de los trabajos reales de Gala.
- Si Gala tiene un CV en PDF, agregalo a esta carpeta y cambiá el botón **Solicitar CV completo** para que enlace al archivo.
- El correo `galadevincenti123@gmail.com` ya está aplicado en los enlaces de contacto.
- Para cambiar colores, ajustá las variables al comienzo de `styles.css`.

## Publicar o actualizar en Vercel

1. Subí `index.html`, `styles.css` y `README.md` al repositorio de GitHub que está conectado al proyecto de Vercel.
2. Vercel va a detectar el cambio y generar un nuevo deploy automáticamente.
3. Cuando el deploy figure como **Ready**, abrí el dominio del proyecto para ver la versión actualizada.

La landing no requiere comandos de build; el preset **Other** y el directorio raíz `./` son suficientes.
